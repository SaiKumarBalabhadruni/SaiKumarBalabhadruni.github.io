# Terminal Resume — GitHub Pages

A terminal-style personal resume / portfolio website.

## Quick start

1. Create a GitHub repository named `<your-username>.github.io`.
2. Replace the placeholder GitHub, LinkedIn and email links in `index.html`.
3. Upload `index.html`, `style.css` and `script.js` to the repository.
4. In **Settings → Pages**, publish from the `main` branch.
5. Your site will be available at `https://<your-username>.github.io/`.

## Customize

- Update the name/title and experience in `index.html`.
- Add your actual GitHub and LinkedIn URLs.
- Add a PDF resume link if desired.
- Change the green terminal accent in `style.css` using `--green`.
